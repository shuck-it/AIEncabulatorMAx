TRAINING DATA AR - hosting bundle

The printed shirt graphic itself is the AR trigger. There is no QR code:
you open this page on your own phone and point it at the shirt.

Phone browsers only allow the camera on a real HTTPS website, so the
camera version needs to live on a static host (all free):

  GitHub Pages:  new public repo -> upload these files -> Settings > Pages ->
                 Deploy from branch "main" / root. URL: https://<you>.github.io/<repo>/
  Netlify Drop:  sign in at app.netlify.com/drop and drag this folder onto the page.
  Cloudflare Pages: Workers & Pages > Create > Pages > Upload assets.

Tip: add the URL to your phone's home screen so it's one tap at the party.
target.mind is compiled from this exact design; if the artwork changes it
must be recompiled.

Test before Halloween with a paper printout of the design.
